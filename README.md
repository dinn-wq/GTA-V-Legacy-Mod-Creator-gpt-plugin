# GTA V Legacy Mod Creator

AI-powered ChatGPT plugin source for creating GTA V Legacy Story Mode mods.

## Features

- Quick Mod Generator
- Mod Recommendation
- One-by-One Mod Builder
- Mod Installation Advisor
- GTA V Legacy Story Mode support
- C# / ScriptHookVDotNet guidance
- NativeUI support when required
- Mod packaging and installation instructions
- Troubleshooting support
- Anti-cheat safeguards

## Recommended Model

GPT-6 is recommended for larger or more complex mod projects.

If GPT-6 is not available, GPT-5.6 or higher is recommended for better consistency with APIs, dependencies, multi-file code, and debugging.

## Important

This project is intended for:

- GTA V Legacy
- Windows PC
- Story Mode / Offline use

Do not use Story Mode script mods in GTA Online.
